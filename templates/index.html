    📤 Upload & Kamera
    Langkah 1 — Input gambar
    • Upload foto JPG, PNG, atau WebP (maks. 10MB)
    • Drag & drop langsung ke area upload
    • Buka kamera perangkat secara real-time
    • Ambil foto langsung dengan tombol capture
    • Preview gambar sebelum dianalisis
    ⚙️ Preprocessing Otomatis
    Langkah 2 — Persiapan data
    • Konversi format ke RGB jika RGBA/grayscale
    • Resize gambar ke 224×224 piksel (LANCZOS)
    • Normalisasi piksel dari [0–255] ke [0–1]
    • Expand dimensi batch untuk input model
    • Proses otomatis di server Flask backend
    🧠 Inferensi MobileNetV2
    Langkah 3 — Analisis AI
    • MobileNetV2 mengekstrak 1.280 fitur visual
    • Depthwise convolution mendeteksi pola warna & tekstur
    • GlobalAveragePooling meringkas fitur spasial
    • Dense layers mengklasifikasikan ke 4 kelas
    • Softmax menghasilkan probabilitas 0–100% per kelas
    📊 Output & Hasil
    Langkah 4 — Tampilan hasil
    • Nama kelas dengan confidence score (%)
    • Bar chart distribusi probabilitas 4 kelas
    • Deskripsi karakteristik biji kopi
    • Rekomendasi metode seduhan terbaik
    • Waktu inferensi dan riwayat prediksi tersimpan
    Informasi Aplikasi

    Tentang Coffee Bean AI

    Tujuan Aplikasi

    Membantu pecinta kopi, barista, pemilik kedai, petani, dan masyarakat mengidentifikasi jenis biji kopi secara otomatis dan akurat menggunakan teknologi AI — tanpa keahlian khusus di bidang machine learning.

    Aplikasi ini dikembangkan sebagai proyek edukasi Machine Learning untuk mendemonstrasikan penerapan computer vision dalam dunia nyata, khususnya pada industri kopi Indonesia.

    Dataset

    Dataset bersumber dari Kaggle: Coffee Bean Dataset Resized 224×224 oleh gpiosenka. Total ±1.600 gambar terbagi ke 4 kelas (Dark, Green, Light, Medium). Proses training dilakukan di Google Colab menggunakan GPU, lalu disimpan sebagai model .h5.

    Lihat Dataset di Kaggle

    Teknologi

    Teknologi utama yang digunakan dalam pengembangan aplikasi ini:

    Python 3.11 TensorFlow 2.21 MobileNetV2 Flask 3.0 Google Colab Railway

    Arsitektur Model

    MobileNetV2 dengan Transfer Learning dari ImageNet. Dilatih dengan strategi 2-fase fine-tuning:

    • Fase 1: Feature extraction — base model di-freeze, hanya melatih Dense layers baru
    • Fase 2: Fine-tuning — membuka 30 layer terakhir dengan learning rate kecil (5e-5)

    Akurasi test: 95%+ · Parameters: 2.4M · Input: 224×224px
